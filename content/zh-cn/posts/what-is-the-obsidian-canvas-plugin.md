## 什么是 Obsidian Canvas？你的库中的无限白板 {#what-is}

Obsidian Canvas 是一个**核心插件**——这意味着它随 Obsidian 一同发布，无需安装——它为你提供了一个无限、可缩放的2D工作空间。你可以将笔记、图片、PDF、视频和网页拖放到一个空白画布上，然后通过绘制线条来展示想法之间的连接。

文件本身以 `.canvas` 文件（底层是 JSON）的形式直接保存在你的库中。用文本编辑器打开它，你会看到坐标、节点ID和边数据——它是纯文本、可移植的，属于你。

**为什么这与标准线性笔记相比很重要？** 笔记列表迫使你选择单一的层级结构。Canvas 则不然。你可以将一个半成熟的想法放在左上角，一个完整的论点放在中心，一堆原始资料放在右侧——并在它们之间绘制箭头，而无需修改任何原始文件。

这更接近人们在复杂项目中的实际思考方式：空间化的、关联的、非线性的。Roam Research 和 Logseq 等工具为我们提供了反向链接来模拟这种方式。Canvas 则在此之上提供了字面上的视觉层。

## 入门：Canvas 初体验（5分钟） {#getting-started}

**首先启用插件。** 前往 *设置 → 核心插件 → Canvas* 并将其打开。完成。

**创建新 Canvas** 有三种方式：
- 命令面板 (`Ctrl/Cmd + P`) → 输入 "New Canvas" (新建画布)
- 右键点击文件浏览器中任意文件夹 → *New Canvas* (新建画布)
- 点击功能区（左侧边栏）中的 Canvas 图标

**导航基础知识：**
- **平移：** 按住 `Space` 并拖动，或点击鼠标中键并拖动
- **缩放：** 滚动鼠标滚轮，或在触控板上捏合
- **适应屏幕：** 按 `Shift + 1` 一次性查看所有内容
- **全选：** `Ctrl/Cmd + A`

底部工具栏有五个按钮：选择、文本卡片、笔记卡片、媒体卡片和链接卡片。这就是你的全部初始工具包。你也可以双击空白区域立即放置一个文本卡片，这是在头脑风暴期间最快的入口。

## 构建模块：理解 Canvas 卡片 {#building-blocks}

Canvas 有四种卡片类型，每种都有其特定用途：

**1. 文本卡片** — 独立的 Markdown 文本。直接在 Canvas 上书写，无需创建笔记文件。这些用于快速标签、问题或你不需要在其他地方引用的简短注释。

**2. 笔记卡片** — 这些卡片嵌入你库中**现有**的笔记。关键是，在 Canvas 上进行的编辑会实时更新源文件。这就是 Canvas 与白板应用的不同之处：你不是复制内容，而是将其呈现在表面。

**3. 媒体卡片** — 拖入图片 (PNG, JPG, SVG)、PDF、音频文件或视频。PDF 会逐页内联渲染，这使得 Canvas 在批注研究论文时与你自己的笔记结合起来非常有用。

**4. 链接/网页卡片** — 粘贴 URL，Canvas 会嵌入一个实时网页。这对于将竞争对手的网站固定在你的分析笔记旁边，或在规划会议期间保持数据仪表盘可见非常有用。

**调整任何卡片的大小** 可以通过拖动角落的句柄。卡片可以做得足够大，无需点击即可完整阅读，这在你将 Canvas 用作一瞥而非编辑的仪表盘时非常重要。

## 建立连接：如何链接和组织你的想法 {#connections}

将鼠标悬停在任意卡片边缘，直到出现一个小圆圈。从该圆圈拖动到另一张卡片以绘制连接线。

**线条选项：**
- **方向：** 线条可以是双向的、单向的，或无连接的（只有一条线，没有箭头）
- **标签：** 双击任意线条以添加标签——例如，“导致”、“与…矛盾”、“引向”
- **颜色：** 右键点击线条选择颜色。对关系类型进行颜色编码（红色=冲突，绿色=支持）是 Canvas 最被低估的功能之一

**组** 是你围绕相关卡片绘制的矩形容器。右键点击空白区域 → *Create group* (创建组)。为组添加标签并赋予其背景颜色。组不强制任何逻辑——它们纯粹是视觉上的——但它们非常适合分离项目阶段或研究地图中的主题集群。

**卡片颜色编码：** 右键点击任意卡片 → *Color* (颜色) 以从六种预设颜色中选择。在所有画布上保持一致使用（例如，黄色=来源，蓝色=我的想法，红色=未解决的问题），你的画布将一目了然。

## 5 种实用案例启发你的灵感 {#use-cases}

### 用例 1：思维导图与头脑风暴

在空白 Canvas 中央放置一个文本卡片，提出一个核心问题。然后用笔记卡片向外分支，每个分支代表一个子主题。绘制带有“例如”或“挑战”等标签的边缘。这是经典的 Obsidian 思维导图设置。与专用思维导图工具相比的优势在于：每个分支都可以链接到一个包含500字支持细节的真实笔记。

关于空间头脑风暴为何有效的理论，[Dan Roam 的《餐巾纸的背面》](URL_PLACEHOLDER_1)值得一读——它是关于视觉思考作为一种解决问题方法的最清晰的书籍论证。

### 用例 2：项目仪表盘

为每个项目创建一个 Canvas。最上面一行：目标笔记 + 关键截止日期（作为文本卡片）。中间一行：每个任务或可交付成果的笔记卡片（这些链接到你的实际任务笔记）。最下面一行：参考资料——PDF、相关笔记、链接到客户简报的网页卡片。一目了然，你无需点击任何文件夹，就能看到项目包含的所有内容。

如果你运行了 Tasks 插件，你的任务笔记卡片会在 Canvas 上显示实时复选框状态。在笔记中完成一个任务，Canvas 卡片会自动更新。

### 用例 3：叙事或演示的故事板

作家和内容创作者：将每个场景或部分作为笔记卡片，从左到右按顺序排列。在每个卡片上方添加一个文本卡片，附带一行摘要。绘制箭头显示故事流。当你通过拖动卡片重新排列部分时，箭头也会随之移动。这比电子表格或便利贴墙更好，因为实际的草稿内容就在每个卡片内部。

### 用例 4：可视化研究主题

将你的源 PDF 文件作为媒体卡片放在左侧。你的文献综述笔记放在中央。你正在形成的论点笔记放在右侧。从特定来源绘制边缘到它们支持的论点。这是一种 zettelkasten 可视化工作流程——你可以一目了然地看到哪些论点有两处来源支持，哪些论点悬而未决。

### 用例 5：构建库主页

许多 Obsidian 用户会创建一个位于库顶部的“主页”Canvas。它包含：一个每日笔记卡片（嵌入当天日期命名的笔记）、一个项目组（链接到每个活跃项目主笔记的卡片）、一个阅读清单卡片和一个目标卡片。打开 Obsidian，打开这个 Canvas，你就能在一个屏幕上获得所有上下文。

要深入了解这些 PKM 工作流程，[这个 Obsidian Skillshare 课程](URL_PLACEHADER_2)以结构化的视频课程涵盖了从每日笔记到 Canvas 仪表盘的完整系统。

## 高级 Canvas 技术与集成 {#advanced}

**在笔记中嵌入 Canvas：** 使用标准的 Obsidian 嵌入语法：`![[my-canvas.canvas]]`。Canvas 会以内联方式渲染为一个小的交互式预览。这对于在项目概览笔记中嵌入项目 Canvas 非常有用。

**图谱视图交互：** Canvas 上的每个笔记卡片都会从 `.canvas` 文件到该笔记创建一个反向链接。打开你的图谱视图，你会看到你的 Canvas 文件作为一个中心节点，向它引用的每个笔记延伸出分支。这意味着 Canvas 活动会反映在你的图谱中，无需任何额外标记。

**Dataview 集成：** Dataview 查询不能直接在 Canvas 文本卡片中运行。解决方法是：创建一个带有 Dataview 查询的专用笔记，然后将**该笔记**作为卡片嵌入到你的 Canvas 上。你将在 Canvas 仪表盘中获得一个实时自动更新的数据表。这对于按标签、状态或日期显示笔记特别强大。

**Canvas 的自定义 CSS：** Obsidian 的 `.canvas-node` CSS 类控制卡片外观。在你的库的 `snippets` 文件夹中放置一小段 CSS 代码，可以更改卡片边框半径、背景颜色默认值或字体大小。Obsidian 论坛的 CSS 部分有现成的 Canvas 代码片段——直接在那里搜索“canvas CSS snippet”。

**对齐工具：** 使用 `Shift + click` 选择多个卡片，然后右键点击以获取对齐选项：左对齐、水平分布、匹配宽度。这些工具可以在大约两分钟内将混乱的头脑风暴内容转换为可读的结构。

## Obsidian Canvas 与其他替代品对比 {#alternatives}

请参阅下一节的完整对比表格。简短版本：

**Canvas 仅在一个维度上优于 Miro 和 Heptabase：** 你的笔记不存储在 Canvas 工具中。它们存储在你的库中。当你嵌入一个笔记卡片时，你看到的是实际的文件。在任何地方更改它，Canvas 都会反映出来。没有导出，没有同步，没有版本不匹配。

**Miro 胜出** 在于你需要实时多用户协作、用于团队研讨会的预设模板，或与 Jira 和 Confluence 的集成。Miro 是一个团队沟通工具。Canvas 是一个个人思考工具。

**Heptabase** 在理念上是最近的竞争对手——它也围绕将可视化卡片链接到笔记而构建——但它是一个订阅 SaaS 应用。你的数据存储在他们的服务器上，并受其定价模型约束。Canvas 是本地优先且免费的。

**Excalidraw** (一个流行的 Obsidian 社区插件，而非核心插件) 在手绘、自定义形状和用于演示的精美图表方面优于 Canvas。如果你需要绘制带自定义样式的箭头或草绘粗略的线框图，Excalidraw 是正确的工具。如果你需要可视化地呈现和连接实际的库内容，Canvas 更好。许多高级用户同时使用两者。

## 故障排除与技巧 {#troubleshooting}

**Canvas 在包含 50+ 张卡片时运行缓慢：** Canvas 会渲染视口中的所有内容。缩小视图时 Obsidian 会加载更多节点，这会增加内存负担。实际的解决方案：将大型 Canvas 分解成更小的子 Canvas，并将其作为卡片嵌入到主 Canvas 中。每个子 Canvas 在点击时打开。

**调整大小时卡片总是跳动：** 这通常是由于 Canvas 缩放级别不是 100% 造成的。缩放到适应屏幕 (`Shift + 1`)，然后调整大小。在标准缩放级别下，卡片会更可预测地对齐。

**我的嵌入笔记卡片没有显示最新内容：** 点击卡片外部的任意位置，然后再次点击卡片。Canvas 会短暂缓存渲染。如果问题持续存在，请关闭并重新打开 Canvas 文件。

**我无法在笔记卡片中滚动：** 单击卡片**一次**以选择它。再次单击以进入编辑/滚动模式。这种两次点击的行为让许多初学者感到困惑。

**Canvas 文件变得很大（加载缓慢）：** 检查 JSON——直接嵌入的非常大的图片会使文件大小膨胀。请引用存储在你的库附件文件夹中的图片，而不是从外部来源拖放；Canvas 会将外部图片作为 base64 存储在 JSON 中，这会很快变得非常大。

## 结论 {#conclusion}

Obsidian Canvas 是近年来 Obsidian 最实用的新增功能之一，正是因为它不要求你改变工作流程。你的笔记依然是笔记。Canvas 只是为它们提供了一个空间化的家，让关系变得可见，而不是隐藏在链接列表中。

从小处着手：本周创建一个项目仪表盘或主页 Canvas。一旦你看到任务笔记在 Canvas 卡片中实时更新，或者看到 Dataview 结果在白板上内联渲染，用例就会自行倍增。

## 常见问题

### Obsidian Canvas 是完全免费的吗？

是的。Canvas 是每个 Obsidian 安装都包含的核心插件。你不需要 Obsidian Sync 或 Obsidian Publish 即可使用它。`.canvas` 文件可以与任何第三方同步解决方案（iCloud、Dropbox、Syncthing）良好同步。

### Canvas 在移动设备上可用吗？

可以，但有局限性。Obsidian 移动应用程序支持 Canvas。平移和缩放通过触摸手势操作。创建和编辑卡片也可用。然而，在手机上，处理包含许多嵌入笔记的复杂 Canvas 时，性能明显慢于桌面端。

### 我可以与他人共享 Canvas 吗？

你可以复制 `.canvas` 文件并发送。接收者需要 Obsidian 并在其库中拥有相同的笔记（文件名匹配），以便笔记卡片能够解析。如果你使用 Obsidian Publish，Canvas 目前无法发布。要向外部共享可视化板，可以截屏或导出为 PDF。

### Canvas 和图谱视图有什么区别？

图谱视图是根据你现有的链接自动生成的——你无法手动定位节点或添加任意连接。Canvas 完全是手动且有意的。可以将图谱视图视为**发现**你现有笔记中的结构，而 Canvas 则是为了特定目的**构建**新结构。

### 我应该使用 Canvas 还是 Excalidraw？

当你的主要需求是可视化地呈现和连接现有库笔记时，请使用 Canvas。当你需要手绘、自定义形状或演示级图表时，请使用 Excalidraw。它们解决的问题不同，并且可以在同一个库中同时存在而不会冲突。
