## 1. 浏览 Obsidian 主题的两种方式：应用内 vs. 网页版 {#two-ways}

Obsidian 为您提供了两个不同的社区主题浏览地点。两者都不是秘密，但大多数指南只解释了其中一个。以下是它们之间的实际区别。

**应用内的社区主题浏览器**位于“设置”中。它会显示所有已发布的主题，允许您预览实时缩略图，并可一键直接安装。无需终端、无需文件拖拽、也无需 GitHub。这是您 90% 的时间会使用的方法。

**官方网页主题库 obsidian.md/themes** 是一个只读的目录。您无法从此处安装主题——它纯粹用于发现。它的优势在于您可以在手机上浏览、与朋友分享链接，或者在午餐时间查看主题而无需打开桌面应用。

| 功能 | 应用内浏览器 | 网页版主题库 |
|---|---|---|
| 无需打开应用即可浏览 | ✗ | ✓ |
| 一键安装 | ✓ | ✗ |
| 实时预览缩略图 | ✓ | ✓ |
| 按亮色/暗色过滤 | ✗ | ✓ |
| 查看下载量 | ✓ | ✗ |
| 检查更新 | ✓ | ✗ |

实际的工作流程是：使用网页版主题库筛选出备选主题，然后在应用内按名称搜索并安装它们。

---

## 2. 分步指南：使用应用内主题浏览器 {#in-app-browser}

这是主要方法。以下是它的具体工作方式。

**导航到正确的设置：** 打开 Obsidian → 点击齿轮图标（左下角）→ 从左侧边栏选择**外观**。向下滚动直到看到**主题**部分。如果您已安装主题，将看到一个“管理”按钮；以及一个**浏览**按钮，用于打开社区浏览器。

**关于受限模式：** 如果您从未安装过插件或主题，Obsidian 会运行在“受限模式”下。社区主题不需要您禁用受限模式——这仅适用于社区*插件*。主题是沙盒化的 CSS 文件，可以自由安装。您只有在以后需要第三方插件时才需要关闭受限模式。

**搜索和排序：** 浏览器会打开一个模态窗口，显示所有可用的社区主题。使用顶部的搜索栏按名称查找特定主题。您也可以按**最新**（最近发布）或**下载量**（最受欢迎）进行排序。按下载量排序是主题是否被积极维护和广泛测试的最可靠指标。

**预览：** 点击任意主题卡片即可展开。您将看到一张屏幕截图和简要描述。预览是静态的——由主题作者提供的屏幕截图——而不是您的知识库的实时渲染。要真正了解主题如何处理您的特定内容，您需要先安装它。

**安装与使用——这个区别很重要：** 当您点击**安装**时，Obsidian 会将主题文件下载到您的知识库的 `.obsidian/themes/` 文件夹中。此时主题已在磁盘上但尚未激活。要实际应用它，您必须点击**使用**（安装后按钮标签会改变）。您可以同时安装多个主题并即时切换。安装几个备选主题，然后快速切换以做决定。

## 3. 如何使用官方网页主题库进行探索 {#web-gallery}

在任何浏览器中访问 [obsidian.md/themes](URL_PLACEHOLDER_1)。页面会加载一个网格，其中包含所有社区主题的屏幕截图缩略图、主题名称和作者。

**筛选：** 在页面顶部，您可以按**亮色模式**或**暗色模式**进行筛选。这是应用内浏览器所缺乏的一个功能，使得网页版主题库对于那些在浏览前就知道自己想要特定模式的用户来说，确实非常有用。

**主题详情页：** 点击主题卡片会打开其详情页。您通常会看到多张屏幕截图，展示主题如何渲染标题、代码块、表格、标签和标注框。如果您处理技术笔记，请密切关注代码块的渲染；如果您的笔记很长且结构化，请关注标题层级。

**关键的下一步：** 网页版主题库没有安装按钮。记下主题的确切名称（复制它），打开 Obsidian，进入“设置 → 外观 → 浏览”，然后将名称粘贴到搜索字段中。它会立即出现。这种两步流程虽然有轻微的摩擦，但您预先收集的预览信息可以节省您安装不适合工作流程主题的时间。

## 4. 安装和管理您的主题 {#installing-managing}

**激活主题：** 安装后，“外观”设置面板会在**当前社区主题**下方显示一个下拉菜单。从列表中选择任何已安装的主题即可立即激活。

**在已安装主题之间切换：** 打开“设置 → 外观 → 滚动到主题部分”。下拉菜单会显示所有已安装的主题。切换是即时且无损的。您之前主题的文件仍然保留在磁盘上。

**检查更新：** Obsidian 不会自动更新主题。要手动检查，请进入“设置 → 外观 → 管理”。任何有待更新的主题都会显示一个**更新**按钮。养成在 Obsidian 主要版本发布后检查的习惯，因为应用更新有时会破坏主题兼容性。

**卸载主题：** 在“管理”视图中，点击您要移除的主题并选择**删除**。这会从 `.obsidian/themes/` 中删除文件。如果该主题是您的活动主题，Obsidian 会自动恢复到默认主题。

## 5. 新手必试的 5 个主题 {#must-try-themes}

这五个主题涵盖了不同的美学风格，并且在 2024 年都得到了积极维护。

| 主题 | 最适合 | 模式 | 风格 |
|---|---|---|---|
| [Minimal](URL_PLACEHOLDER_2) | 专注、无干扰写作 | 亮色 + 暗色 | 极简、宽敞 |
| Things | 精致的日常使用 | 亮色 + 暗色 | 灵感来自 Things 3 应用 |
| AnuPpuccin | 视觉吸引力、色彩多样性 | 亮色 + 暗色 | 柔和色调，基于 Catppuccin |
| Primary | 高级用户、高度自定义 | 亮色 + 暗色 | 功能丰富、样式系统 |
| Atom | 技术 / 代码密集型知识库 | 暗色 | 经典代码编辑器 |

**Minimal** 是生态系统中下载量最大的主题，原因显而易见。它消除了视觉噪音，并与 Style Settings 插件配合得非常好，让您无需编写 CSS 即可获得精细控制。

**AnuPpuccin** 是如果您希望您的知识库感觉温暖而协调的首选。它自带多种可通过 Style Settings 选择的调色板。

**Things** 复刻了 Things 3 任务管理器的精致 UI。如果您将 Obsidian 用于项目规划和笔记，视觉一致性会有所帮助。

## 6. 更进一步：使用 CSS Snippets 自定义主题 {#css-snippets}

CSS snippets 是小型 `.css` 文件，它们叠加在您当前激活的主题之上。它们允许您修复一个特定的问题——比如字体大小、颜色、边距——而无需修改主题本身，也无需等待主题作者推送更新。

**Snippets 的存放位置：** 您的知识库文件夹 → `.obsidian/snippets/`。如果此文件夹不存在，请创建它。

**如何启用 Snippet：** 设置 → 外观 → 滚动到**CSS Snippets** → 切换打开 Snippet。Obsidian 会热重载 Snippets，因此更改会立即应用，无需重启。

**查找 Snippets：** [Obsidian 论坛的“分享与展示”版块](URL_PLACEHOLDER_4)是最好的来源。用户会在那里发布可直接粘贴的 Snippets，用于特定的调整。在论坛中搜索您的主题名称加上您尝试解决的问题（例如，“Minimal theme tag color snippet”）。

**一个具体示例：** 如果您的 H1 标题感觉太小，请在您的 Snippets 文件夹中创建一个名为 `heading-fix.css` 的文件，并添加：

```css
.markdown-rendered h1,
.cm-header-1 {
  font-size: 2em;
}
```

在“外观”设置中启用它即可。就这么简单。更改会同时应用于阅读视图和实时预览。

当主题更新破坏了您所依赖的某个功能时，Snippets 也是正确的工具。此时，与其回滚主题，不如编写一个小 Snippet 来恢复更改的特定属性。

## 7. 常见主题问题排查 {#troubleshooting}

**Obsidian 更新后主题显示异常：** 核心应用更新偶尔会改变内部 CSS 类名。主题可能尚未跟进。请检查主题的 GitHub 页面，查看是否有未解决的问题或最近的提交。如果没有，请暂时恢复到默认主题，并在一周后再次检查。

**与插件冲突：** 有些插件会注入自己的 UI 元素。如果只有在特定插件打开时才出现显示问题，请暂时禁用您的主题（切换到默认主题），看看布局问题是否消失。如果消失，则冲突是主题特有的——请在插件的 GitHub 页面上报告此问题。

**移动端与桌面端渲染差异：** Obsidian Mobile 使用相同的主题，但有些主题并未针对移动屏幕宽度进行优化。请寻找在 README 中明确提及支持移动端的主题。

**在哪里寻求帮助：** [官方 Obsidian 论坛](URL_PLACEHOLDER_4)有一个专门的主题频道。Obsidian Discord 在快速提问方面更快。寻求帮助时，请务必包含您的 Obsidian 版本、主题名称和版本以及屏幕截图。

如果您想让您的 Obsidian 设置从功能性转变为每天都真正令人愉悦的使用体验，美学的重要性远超大多数效率作家所承认的。一个看起来舒适的知识库，才是一个您会真正打开的知识库。这正是[构建一个坚实的个人知识系统](URL_PLACEHOLDER_5)的意义所在。

## 常见问题

### 问：我需要为社区主题付费吗？

不需要。官方 Obsidian 主题浏览器中的所有主题都是免费且开源的。一些主题作者接受通过 Ko-fi 或 GitHub Sponsors 捐赠，但绝不强制付费。

### 问：我可以在 Obsidian 移动版上使用主题吗？

是的。如果您启用了 Obsidian Sync，主题会在桌面版和移动版之间同步。在桌面版上安装主题后，它会在下次同步后出现在您的移动设备上。并非所有主题都针对移动设备进行了优化，因此请查看主题描述。

### 问：安装主题会减慢我的知识库吗？

不会。主题是启动时加载的 CSS 文件。它们对 Obsidian 的性能没有可衡量的影响。CSS snippets 也不会产生任何性能成本。

### 问：如何恢复到默认的 Obsidian 外观？

设置 → 外观 → 当前社区主题 → 选择**默认**。您已安装的主题仍保留在磁盘上，但处于非活动状态。

### 问：我可以直接编辑社区主题吗？

理论上可以——文件位于 `.obsidian/themes/`。但实际上，请避免直接编辑它们，因为更新会覆盖您的更改。请改用 CSS snippets 来应用有针对性的覆盖，这些覆盖可以在更新后继续生效。

**安装与使用——这个区别很重要：** 当您点击**安装**时，Obsidian 会将主题文件下载到您的知识库的 `.obsidian/themes/` 文件夹中。此时主题已在磁盘上但尚未激活。要实际应用它，您必须点击**使用**（安装后按钮标签会改变）。您可以同时安装多个主题并即时切换。安装几个备选主题，然后快速切换以做决定。

## 3. 如何使用官方网页主题库进行探索 {#web-gallery}

在任何浏览器中访问 [obsidian.md/themes](URL_PLACEHOLDER_1)。页面会加载一个网格，其中包含所有社区主题的屏幕截图缩略图、主题名称和作者。

**筛选：** 在页面顶部，您可以按**亮色模式**或**暗色模式**进行筛选。这是应用内浏览器所缺乏的一个功能，使得网页版主题库对于那些在浏览前就知道自己想要特定模式的用户来说，确实非常有用。

**主题详情页：** 点击主题卡片会打开其详情页。您通常会看到多张屏幕截图，展示主题如何渲染标题、代码块、表格、标签和标注框。如果您处理技术笔记，请密切关注代码块的渲染；如果您的笔记很长且结构化，请关注标题层级。

**关键的下一步：** 网页版主题库没有安装按钮。记下主题的确切名称（复制它），打开 Obsidian，进入“设置 → 外观 → 浏览”，然后将名称粘贴到搜索字段中。它会立即出现。这种两步流程虽然有轻微的摩擦，但您预先收集的预览信息可以节省您安装不适合工作流程主题的时间。

## 4. 安装和管理您的主题 {#installing-managing}

**激活主题：** 安装后，“外观”设置面板会在**当前社区主题**下方显示一个下拉菜单。从列表中选择任何已安装的主题即可立即激活。

**在已安装主题之间切换：** 打开“设置 → 外观 → 滚动到主题部分”。下拉菜单会显示所有已安装的主题。切换是即时且无损的。您之前主题的文件仍然保留在磁盘上。

**检查更新：** Obsidian 不会自动更新主题。要手动检查，请进入“设置 → 外观 → 管理”。任何有待更新的主题都会显示一个**更新**按钮。养成在 Obsidian 主要版本发布后检查的习惯，因为应用更新有时会破坏主题兼容性。

**卸载主题：** 在“管理”视图中，点击您要移除的主题并选择**删除**。这会从 `.obsidian/themes/` 中删除文件。如果该主题是您的活动主题，Obsidian 会自动恢复到默认主题。

## 5. 新手必试的 5 个主题 {#must-try-themes}

这五个主题涵盖了不同的美学风格，并且在 2024 年都得到了积极维护。

| 主题 | 最适合 | 模式 | 风格 |
|---|---|---|---|
| [Minimal](URL_PLACEHOLDER_2) | 专注、无干扰写作 | 亮色 + 暗色 | 极简、宽敞 |
| Things | 精致的日常使用 | 亮色 + 暗色 | 灵感来自 Things 3 应用 |
| AnuPpuccin | 视觉吸引力、色彩多样性 | 亮色 + 暗色 | 柔和色调，基于 Catppuccin |
| Primary | 高级用户、高度自定义 | 亮色 + 暗色 | 功能丰富、样式系统 |
| Atom | 技术 / 代码密集型知识库 | 暗色 | 经典代码编辑器 |

**Minimal** 是生态系统中下载量最大的主题，原因显而易见。它消除了视觉噪音，并与 Style Settings 插件配合得非常好，让您无需编写 CSS 即可获得精细控制。

**AnuPpuccin** 是如果您希望您的知识库感觉温暖而协调的首选。它自带多种可通过 Style Settings 选择的调色板。

**Things** 复刻了 Things 3 任务管理器的精致 UI。如果您将 Obsidian 用于项目规划和笔记，视觉一致性会有所帮助。

## 6. 更进一步：使用 CSS Snippets 自定义主题 {#css-snippets}

CSS snippets 是小型 `.css` 文件，它们叠加在您当前激活的主题之上。它们允许您修复一个特定的问题——比如字体大小、颜色、边距——而无需修改主题本身，也无需等待主题作者推送更新。

**Snippets 的存放位置：** 您的知识库文件夹 → `.obsidian/snippets/`。如果此文件夹不存在，请创建它。

**如何启用 Snippet：** 设置 → 外观 → 滚动到**CSS Snippets** → 切换打开 Snippet。Obsidian 会热重载 Snippets，因此更改会立即应用，无需重启。

**查找 Snippets：** [Obsidian 论坛的“分享与展示”版块](URL_PLACEHOLDER_4)是最好的来源。用户会在那里发布可直接粘贴的 Snippets，用于特定的调整。在论坛中搜索您的主题名称加上您尝试解决的问题（例如，“Minimal theme tag color snippet”）。

**一个具体示例：** 如果您的 H1 标题感觉太小，请在您的 Snippets 文件夹中创建一个名为 `heading-fix.css` 的文件，并添加：

```css
.markdown-rendered h1,
.cm-header-1 {
  font-size: 2em;
}
```

在“外观”设置中启用它即可。就这么简单。更改会同时应用于阅读视图和实时预览。

当主题更新破坏了您所依赖的某个功能时，Snippets 也是正确的工具。此时，与其回滚主题，不如编写一个小 Snippet 来恢复更改的特定属性。

## 7. 常见主题问题排查 {#troubleshooting}

**Obsidian 更新后主题显示异常：** 核心应用更新偶尔会改变内部 CSS 类名。主题可能尚未跟进。请检查主题的 GitHub 页面，查看是否有未解决的问题或最近的提交。如果没有，请暂时恢复到默认主题，并在一周后再次检查。

**与插件冲突：** 有些插件会注入自己的 UI 元素。如果只有在特定插件打开时才出现显示问题，请暂时禁用您的主题（切换到默认主题），看看布局问题是否消失。如果消失，则冲突是主题特有的——请在插件的 GitHub 页面上报告此问题。

**移动端与桌面端渲染差异：** Obsidian Mobile 使用相同的主题，但有些主题并未针对移动屏幕宽度进行优化。请寻找在 README 中明确提及支持移动端的主题。

**在哪里寻求帮助：** [官方 Obsidian 论坛](URL_PLACEHOLDER_4)有一个专门的主题频道。Obsidian Discord 在快速提问方面更快。寻求帮助时，请务必包含您的 Obsidian 版本、主题名称和版本以及屏幕截图。

如果您想让您的 Obsidian 设置从功能性转变为每天都真正令人愉悦的使用体验，美学的重要性远超大多数效率作家所承认的。一个看起来舒适的知识库，才是一个您会真正打开的知识库。这正是[构建一个坚实的个人知识系统](URL_PLACEHOLDER_5)的意义所在。

## 常见问题

### 问：我需要为社区主题付费吗？

不需要。官方 Obsidian 主题浏览器中的所有主题都是免费且开源的。一些主题作者接受通过 Ko-fi 或 GitHub Sponsors 捐赠，但绝不强制付费。

### 问：我可以在 Obsidian 移动版上使用主题吗？

是的。如果您启用了 Obsidian Sync，主题会在桌面版和移动版之间同步。在桌面版上安装主题后，它会在下次同步后出现在您的移动设备上。并非所有主题都针对移动设备进行了优化，因此请查看主题描述。

### 问：安装主题会减慢我的知识库吗？

不会。主题是启动时加载的 CSS 文件。它们对 Obsidian 的性能没有可衡量的影响。CSS snippets 也不会产生任何性能成本。

### 问：如何恢复到默认的 Obsidian 外观？

设置 → 外观 → 当前社区主题 → 选择**默认**。您已安装的主题仍保留在磁盘上，但处于非活动状态。

### 问：我可以直接编辑社区主题吗？

理论上可以——文件位于 `.obsidian/themes/`。但实际上，请避免直接编辑它们，因为更新会覆盖您的更改。请改用 CSS snippets 来应用有针对性的覆盖，这些覆盖可以在更新后继续生效。
