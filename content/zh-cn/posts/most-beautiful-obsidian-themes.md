## 为什么您的 Obsidian 主题不仅仅是好看 {#why-theme-matters}

您的视觉环境与持续认知工作的质量之间存在着有据可查的关系。Don Norman 在 [*《日常物品设计》*](URL_PLACEHOLDER_1) 中对此进行了深入探讨——其核心论点是，设计精良的物品会让人乐于使用，而设计不佳的工具会产生摩擦，并随着时间的推移而加剧。同样的逻辑也适用于软件。

如果您每天打开 Obsidian，默认界面却让您无感——没有期待，没有舒适，没有一丝愉悦——那么您就浪费了激励能量。这对于笔记记录来说尤为重要，因为它是一种习惯，而非一项任务。习惯的养成和消亡取决于其开始的难易程度，而视觉吸引力是合法的切入点。

它也有实际意义。对比度差的主题会在 45 分钟后使您的眼睛疲劳。标题层级混乱的主题会使您自己的笔记难以快速浏览。排版选择会影响阅读速度。这些不是审美偏好；它们是可用性变量，并会在每次会话中累积。

从 Obsidian 的默认外观转向精心选择的主题，目标不是装饰。它是将一个功能性工具转化为一个您积极愿意花时间工作的空间。把它想象成荧光灯办公室和精心设计的工作室之间的区别——工作在技术上是相同的，但其中一个版本会持续产生更好的输出。

## 我们如何评判“精美”：我们的策展标准 {#curation-criteria}

本文中的每个主题都根据四个具体标准进行评估。这并非社区浏览器中所有主题的堆砌。

**美学统一性**
每个元素——侧边栏、编辑窗格、标题、代码块、标签、图视图——是否感觉都属于同一个设计系统？那些在编辑器中看起来很精致但在设置或图视图中显得混乱的主题未被选中。

**高负荷下的可读性**
每个主题都在 90 分钟的写作会话中进行了测试，在适用情况下同时测试了亮色和深色模式。对比度根据 WCAG AA 标准进行了检查。如果您的眼睛感到不适，无论截图看起来多么漂亮，该主题都会被淘汰。

**Style Settings 兼容性**
[Style Settings 插件](URL_PLACEHOLDER_2)是一个社区插件，它在 Obsidian 内部提供了一个设置面板，您可以在其中更改字体、切换功能、调整颜色强调等——而无需触碰任何一行 CSS 代码。提供深度 Style Settings 集成的主题得分更高，因为它们让您无需编码知识即可进行控制。

**积极维护**
Obsidian 会定期更新其 API。一个最后在 2021 年触碰过的主题将会崩溃。截至本文撰写之时，这里列出的每个主题在过去八个月内都有 GitHub 提交记录。

## 类别 1：极简与整洁主题，实现极致专注 {#minimalist-themes}

极简主题移除了所有不直接服务于阅读或写作的元素。没有渐变，没有装饰元素，减少了 UI 装饰。如果您的工作涉及长时间写作——您是小说家、研究员或日常日记作者——这些主题将最大程度地提高您的生产力。

### Things

**Things** 由 [Colin Hou](URL_PLACEHOLDER_3) 制作，有一个清晰的参考点：它希望 Obsidian 感觉像一个原生的 macOS 应用程序。侧边栏使用柔和的灰色，活动笔记指示器是干净的蓝色强调色，整体印象更接近 Bear 或 Apple Notes，而不是开发人员工具。

Things 的突出之处在于它对标题的处理。H1 到 H3 按比例缩放，并具有合理的粗细差异，因此笔记结构可以立即阅读，而无需标题过于醒目。代码块的样式简洁，背景浅色，不会中断阅读流程。

**最佳搭配：**
- **Style Settings**：在棕褐色、纯白色和冷灰色基色之间切换
- **Banners**：添加全宽标题图像，在 Things 简洁的布局中完美呈现
- **Minimal Theme Settings**：通过 Style Settings 切换提供等效的自定义功能

**适合：** macOS 用户、作家、从 Apple Notes 或 Bear 转用者

---

### Minimal

如果您只安装一个主题，Kepano 的 **Minimal** 无疑是最稳妥的选择。自 2020 年以来，它一直持续维护，附带一个专用配套插件 (Minimal Theme Settings)，其理念无可辩驳：剥离所有非必需品，然后让 Style Settings 和配套插件让您精确添加所需内容。

默认状态几乎是激进的朴素——这就是重点。一旦您安装了配套插件和 Style Settings，您就可以控制卡片布局、图像网格、复选框样式、焦点模式、行宽、标题大小和表格样式。其自定义深度在免费主题中无与伦比。

Minimal 中的图视图也脱颖而出：节点颜色会根据您选择的强调色进行调整，而不是保持固定，这听起来微不足道，直到您亲眼看到它。

**最佳搭配：**
- **Minimal Theme Settings 插件**（强制配套——请立即安装）
- **Dataview**：Minimal 的卡片和表格样式使 Dataview 输出真正吸引人
- **Kanban**：在 Minimal 的卡片布局模式下，Kanban 看板渲染清晰

**适合：** 高级用户、开发人员、任何需要长期灵活性的人

---

### Typora-Vesper

**Vesper** 不像前两个主题那样广为人知，这是社区正在慢慢纠正的错误。它借鉴了代码编辑器中流行的 Vesper 调色板设计线索——深炭色背景配以温暖的琥珀色和奶油色强调色——并将其应用于无干扰的写作界面。

主要区别在于其 Markdown 渲染理念。Vesper 在实时预览中比其他主题更激进地隐藏 Markdown 语法，因此在您写作时，星号、括号和井号几乎完全消失。屏幕上呈现的是干净的散文。切换到标题行时，您会看到结构；移开时，标记则隐藏。它真正改变了在 Obsidian 中写作的感觉。

**最佳搭配：**
- **Typewriter Scroll 插件**：使当前行居中——与 Vesper 的写作焦点完美搭配
- **Word Count**：Vesper 的状态栏区域处理插件的输出，没有视觉混乱

**适合：** 作家、记者、从事长篇散文工作的人

## 类别 2：舒适与精致的深色模式主题 {#dark-mode-themes}

这些主题是为那些生活在深色模式中，并希望获得比简单反色方案更温暖或更精致体验的人设计的。它们优先考虑在夜间会话中的眼睛舒适度、丰富的调色板和整体的视觉工艺感。

### Nord

**Nord** 基于 [Nord 调色板](URL_PLACEHOLDER_4)——一套受北极启发的冷蓝色、柔和的青色和白色调，最初是为代码编辑器开发的。它很早就迁移到 Obsidian 主题中，并积累了社区主题中最大的用户群之一。

其吸引力在于一致性。如果您已经在终端、代码编辑器或系统主题中使用了 Nord，那么您的 Obsidian 库将与您的整个设置保持一致。蓝色足够去饱和，以避免视觉疲劳，深色背景是真正的深海军蓝色而不是纯黑色，文本的对比度水平足以在长时间会话中保持清晰。

Obsidian 中的 Nord 也能出色地渲染代码块，这使其成为开发人员记录技术笔记的自然选择。

**最佳搭配：**
- **Style Settings**：在较深和较浅的 Nord 变体之间切换
- **Excalidraw**：当您使用匹配的描边颜色时，Nord 调色板会延续到 Excalidraw 草图
- **Code Block Copy**：Nord 的代码块阅读起来非常舒服——复制按钮插件对其进行了补充

**适合：** 开发人员、工程师、系统主题一致性爱好者

---

### Sanctum

**Sanctum** 位于深色模式光谱的另一端，与 Nord 形成对比。如果说 Nord 是冷酷和实用的，那么 Sanctum 则是温暖、浓郁且刻意精致的。它使用深棕灰色背景而不是蓝黑色，并将其与柔和的金色和奶油色搭配用于标题，给整个库带来一种更接近精心设计的出版物而非软件界面的感觉。

Sanctum 的排版选择尤其出色。默认的标题堆栈创建了清晰的视觉层次，正文文本的字重也经过精心调整以提高可读性。侧边栏使用微妙的分隔线而不是厚重的边框，这使得界面保持统一感。

如果您想让您的个人知识管理库感觉像一个“图书馆”——经过深思熟虑、从容不迫、严肃认真——那么 Sanctum 是免费 Obsidian 主题中最接近这种感觉的。

**最佳搭配：**
- **Banners**：Sanctum 中的标题图像感觉更像是精心策划而非装饰
- **Calendar plugin**：Sanctum 的侧边栏处理使 Calendar 小部件看起来真正精致
- **Sliding Panes**：在 Sanctum 的间距下，多个窗格感觉是有意的而非杂乱无章

**适合：** 学术研究人员、Zettelkasten 实践者、构建长期知识库的作家

---

### Everforest

**Everforest** 汲取了 Sanctum 的温暖，并将其注入了绿色。基于 sainnhe 的 Everforest 配色方案，Obsidian 移植版为您的库带来了深森林绿、大地棕和柔和的黄色。效果确实很舒适——视觉上相当于在窗边有树木的房间里工作。

温暖的深色背景（完全避免了冷灰色）使其成为在夜间会话中最容易看的主题之一。强调色经过精心平衡，使得代码块、标签和标注都保持可读性，没有任何元素抢夺注意力。

**最佳搭配：**
- **Style Settings**：在硬、中、软背景变体之间切换
- **Dataview**：Everforest 下的表格样式简洁，并有效地使用了绿色强调色
- **Tasks plugin**：复选框和任务指示器使用 Everforest 的调色板，而不会破坏视觉平静

**适合：** 夜间笔记记录者、自然美学爱好者、任何觉得冷色调深色模式过于单调的人

## 类别 3：活力与独特主题，激发乐趣 {#vibrant-themes}

这些主题不会试图隐藏自己。它们拥有个性、色彩和视觉抱负。如果您想让您的库感觉像一个创意空间，而不是一个生产力工具，那么这就是您的类别。

### Primary

Cecilia May 的 **Primary** 是整个 Obsidian 社区中最具原创性的主题之一。其设计语言明显受包豪斯风格启发：原色、大胆的边框、几何形状，以及一种刻意的扁平化，看起来活泼而非幼稚。库的 UI 感觉更像一个精心设计的实体规划器，而不是一个软件应用程序。

Primary 中的标题大胆且带有色块。复选框使用粗线条。侧边栏具有清晰的视觉结构。它的一切都毫不掩饰地展示着可见性。如果极简主义让您感到匮乏，Primary 会让您感到轻松。

**最佳搭配：**
- **Kanban**：Primary 设计系统中的卡片边框使看板看起来像是专为此主题而设计的
- **Banners**：明亮的标题图像与 Primary 的色彩自信相得益彰，而非冲突
- **Colored Tags plugin**：Primary 的标签样式 + 自定义标签颜色创建了一个真正有趣味的组织系统

**适合：** 创意专业人士、学生、子弹日记爱好者、觉得单色工具令人沮丧的人

---

### AnuPpuccin

**AnuPpuccin** 基于 [Catppuccin 调色板](URL_PLACEHOLDER_5)——四种口味（Latte、Frappé、Macchiato、Mocha）的柔和蜡笔色，在开发人员工具中变得非常流行。AnubisNekhet 的 Obsidian 移植版扩展了基本调色板，进行了大量的 UI 自定义，并位列 2024 年下载量最高的社区主题之一。

AnuPpuccin 与纯粹的调色板移植版不同之处在于它附带的自定义 CSS：备用复选框、彩虹文件夹颜色、自定义标注样式和可通过 Style Settings 访问的动画元素。您可以花一个小时自定义 AnuPpuccin，最终得到一个与其他人截然不同的库，即使使用相同的基础主题。

柔和的蜡笔色方法也意味着它在亮色（Latte）和深色（Mocha、Macchiato）模式下都能很好地工作，而不会感觉像是两个独立的主题。

**最佳搭配：**
- **Style Settings**（必不可少——AnuPpuccin 的自定义面板异常深入）
- **Iconize**：以 Catppuccin 强调色呈现的自定义文件夹图标具有视觉凝聚力且易于识别
- **Hider plugin**：隐藏您不需要的 UI 元素，使柔和的蜡笔美学更加鲜明

**适合：** 注重设计的用户、学生、已经在其工具中使用 Catppuccin 的人

---

### Prism

damiankorcz 的 **Prism** 独树一帜。其显著特点是其色彩处理方法：Prism 不拘泥于一种调色板，而是提供了一个通过 Style Settings 访问的广泛色彩方案预设库，并支持应用于标题和 UI 元素的自定义渐变强调色。

实现技术令人印象深刻——特别是应用于 H1-H3 标题的渐变，使结构化笔记在视觉上具有其他免费主题无法比拟的编辑感。无需离开 Obsidian 设置，即可在酷炫的赛博朋克调色板和温暖的日落调色板之间切换。Prism 的图视图也十分出色，它使用活动强调色对节点连接进行颜色编码。

权衡之处在于：由于 Prism 提供了太多功能，将其配置到您满意稳定状态所需的时间会更长。请预留 20-30 分钟进行设置。

**最佳搭配：**
- **Style Settings**（访问 Prism 完整调色板库的必备条件）
- **Graph Analysis plugin**：Prism 的图视图足够出色，值得花时间使用
- **Obsidian Charts**：Prism 的颜色系统能有效地融入图表渲染

**适合：** 视觉思考者、维护大型互联库的人、设计师

## 您的快速指南：安装与切换主题 {#how-to-install}

安装社区主题不到两分钟。以下是具体路径：

**步骤 1：打开外观设置**
前往 `设置 → 外观`。滚动到“主题”部分，点击“管理”或“浏览社区主题”。

**步骤 2：搜索并安装**
Obsidian 内部会打开社区主题浏览器。按名称搜索（例如，“Minimal”或“AnuPpuccin”），点击主题，然后点击“安装并使用”。主题会立即激活。

**步骤 3：切换主题**
返回 `设置 → 外观 → 主题`。下拉菜单显示所有已安装的主题。您可以随时切换，而不会丢失笔记或设置。

**专业提示：立即安装 Style Settings**
前往 `设置 → 社区插件 → 浏览`，搜索“Style Settings”，安装并启用它。然后返回 `设置 → Style Settings`——如果您的活动主题支持，将出现一个完整的自定义面板。无需代码即可更改字体、切换 UI 元素、调整强调色。

**想要超越 Style Settings 所允许的范围？** 基础 CSS 技能可以完全控制 Obsidian 中的每个视觉元素。一个实用的起点是 [Skillshare 上的 CSS 初学者课程](URL_PLACEHOLDER_6)，它将让您在几个小时内从零开始编写功能片段。Obsidian 原生支持在 `设置 → 外观 → CSS 片段` 下的 CSS 片段。

## 超越主题：使用这些插件完善您的美学 {#aesthetic-plugins}

主题奠定了基础。这些插件对其进行了扩展。

### Banners
Banners 插件在任何笔记的顶部添加一个全宽图像。添加一个 YAML 属性 (`banner: "path/to/image.jpg"`)，笔记就会以标题图像打开。在 Sanctum、Minimal 或 Things 主题下，效果显著——笔记不再像文档，而开始像页面。与 Unsplash 图像或您自己的摄影作品搭配效果很好。

### Iconize (自定义图标)
Iconize 允许您为侧边栏中的单个文件、文件夹或文件类型分配图标。实际效果非常显著：一个精心选择文件夹图标的库可以一目了然地导航，而无需阅读文本。在 AnuPpuccin 或 Primary 主题下，以强调色调色板渲染的图标使侧边栏感觉像是专门设计而非通用。

### Supercharged Links
Supercharged Links 为您的库中所有内部链接添加视觉元数据。您可以将其配置为根据链接的属性显示彩色点、表情符号或前缀文本——因此，指向标记为 `#book` 的笔记的链接显示一个书籍表情符号，指向 `#person` 笔记的链接显示一个姓名样式的​​前缀。在任何充满活力的主题下，这都会创建一个真正可视化的链接系统。

### 通过 Envato Elements 使用自定义字体
如果您想将您的库的排版提升到免费主题包无法提供的水平，[Envato Elements](URL_PLACEHOLDER_7) 是一项订阅服务，包含数千种高级字体和图标集。通过 Obsidian 的 `设置 → 外观 → 文本字体` 字段加载下载的字体（在系统范围内安装后指定字体系列名称）。将 Minimal 或 Sanctum 与高级衬线正文字体搭配使用会显著改变阅读体验。

上述九个主题涵盖了实践中精美 Obsidian 主题的现实范围。总结实际决策：

- 如果您想少思考界面，多专注于写作：**Minimal** 或 **Things**
- 如果您晚上花时间在您的库中，并想要温暖感：**Everforest** 或 **Sanctum**

安装 Style Settings 搭配其中任何一个。添加 Banners 和 Iconize 以完成设置。给自己 30 分钟进行配置，而不是期望默认安装是完美的。

## 常见问题

### 安装主题会以任何方式影响我的笔记或库数据吗？

不会。主题是纯 CSS——它们只改变您的库外观，不改变任何其他内容。您的笔记、链接、附件和插件数据与主题文件完全分离。您可以自由安装、切换和卸载主题，对您的内容零风险。

### 我的主题在 Obsidian 更新后看起来坏了。我该怎么办？

当 Obsidian 的 API 发生变化并且主题 CSS 引用旧类名时会发生这种情况。请检查主题的 GitHub 存储库是否有最近的提交或开放问题。对于此列表中的主题，开发人员都很活跃，通常会在 Obsidian 更新后几天内推出修复程序。在此期间，切换到备用主题（Minimal 是一个安全的备选——它更新很快）。

### 我可以同时使用多个主题或组合两个主题的元素吗？

不能直接。一次只能激活一个主题。但是，您可以使用 CSS 片段（`设置 → 外观 → CSS 片段`）来覆盖您活动主题中的特定元素。如果您习惯编写基本 CSS，这允许您借用例如一个主题的标题样式，同时保留另一个主题的调色板。

### 哪个主题最适合有阅读障碍或阅读困难的人？

Minimal 和 Things 是最强的起点，因为它们的排版清晰且间距宽敞。在这两个主题中，通过 Style Settings 增加行高和字体大小。Everforest 和 Sanctum 的暖色调背景也减少了纯白色或纯黑色背景造成的刺眼感，一些有阅读敏感性的人会觉得这很有帮助。

### 这些主题在 Obsidian 移动版（iOS/Android）上也能使用吗？

是的，这里列出的所有主题都支持移动设备。质量略有不同——某些 Style Settings 选项仅限于桌面版。核心视觉体验（颜色、排版、布局）在移动设备上正确传输。如果您经常使用手机库，Minimal 的配套插件具有特定的移动布局优化，值得启用。
